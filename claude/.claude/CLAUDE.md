# Global Claude Code instructions

Stowed from the dotfiles repo (`claude/.claude/CLAUDE.md` → `~/.claude/CLAUDE.md`).
Applies to every project; project `CLAUDE.md` files take precedence.

## Handoffs

When `/mattpocock-skills:handoff` is used, save the handoff document(s) as
Markdown under `.prompts/` in the current project (e.g.
`.prompts/handoff-<topic>.md`, one file per topic), not in the OS temp
directory the skill suggests. Never overwrite existing files there.
